# types-blinkpy

Type stubs for the [blinkpy](https://github.com/fronzbot/blinkpy) package.

## Installation

```bash
pip install types-blinkpy
```

## Usage

These stubs provide type information for the blinkpy package. Install them alongside blinkpy for better type checking:

```bash
pip install blinkpy types-blinkpy
```

The stubs will be automatically discovered by type checkers like mypy, pyright, and pylance.

## Compatibility

- Compatible with blinkpy 0.24.0+
- Requires Python 3.12+

## Development

This package contains type stubs (`.pyi` files) for the blinkpy library, providing type information for:

- `blinkpy.Blink` - Main Blink class
- `blinkpy.BlinkCamera` - Camera management
- `blinkpy.BlinkSyncModule` - Sync module operations
- `blinkpy.api` - API functions
- `blinkpy.auth` - Authentication handling
- `blinkpy.livestream` - Live streaming functionality
- `blinkpy.helpers` - Utility functions and constants
